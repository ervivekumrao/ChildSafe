## 📱 About Child Safe

**Child Safe** is a comprehensive parental control solution designed to help parents monitor and manage their children's digital activities. The app provides a secure environment for device usage, ensuring children stay safe while exploring the digital world.

---

## ✨ Key Features

*   🛡️ **Device Monitoring** – Real-time insights into your child's device activities.
*   🚫 **App Management** – Control which applications your child can install and access.
*   ⏳ **Usage Restrictions** – Set healthy screen time limits and daily schedules.
*   📍 **Location Tracking** – Stay informed about your child's location at any time.
*   🔐 **Kiosk Mode** – Transform the device into a secure, restricted environment with authorized apps only.
*   ⚙️ **Advanced Management** – Professional-grade administrative controls to prevent unauthorized app removal.
*   🌙 **Dark Mode Support** – A comfortable viewing experience for all lighting conditions.
*   🔒 **Secure Access** – Everything is protected by your personal PIN and password.

## 🚀 How to Use Child Safe

Getting started is simple. Follow these steps to secure your child's device:

### 1. Install the App
Download and install **Child Safe** from the [Google Play Store](https://play.google.com/store/apps/details?id=control.child.device) on both the Parent's device and the Child's device.

### 2. Set Up the Parent Device
*   Open the app and select **"Parent"** as the user type.
*   Create an account or sign in.
*   This device will serve as your control center to monitor and set rules.

### 3. Set Up the Child Device (Enrollment)
For the best experience and full control, we recommend using **QR Code Enrollment**:

1.  **Factory Reset** the child's device (recommended for full management).
2.  On the initial setup screen, tap the screen 6 times in the same spot to trigger the QR scanner.
3.  Scan the **Enrollment QR Code** provided in your Parent Dashboard.
4.  The device will automatically download Child Safe and configure itself as a managed device.

*Alternatively, you can manually install the app, select **"Child"** as the user type, and follow the on-screen linking instructions.*

### 4. Configure Rules
From your Parent Dashboard, you can now:
*   Approve or block apps.
*   Set daily time limits.
*   View live location and activity logs.

## 🛠️ Advanced Management

The **Advanced Management** section (formerly "Danger Zone") allows parents to exercise full control over the device's administrative settings. Use this to:
*   Enable **End Device Management** for complete oversight.
*   Manage **Quick Sign Out** options.
*   Ensure the parental control layer cannot be bypassed or uninstalled without authorization.
